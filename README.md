# 💻 Laptop Price Prediction

An interactive **Streamlit** application for predicting laptop prices using **50+ hardware and software features**.  
The project integrates advanced feature engineering, machine learning models, and a production-ready inference pipeline.

---

## 🚀 Features

- **Interactive Web App** built with Streamlit for easy price prediction.
- **Advanced Feature Engineering**:
  - PPI (Pixels Per Inch)
  - CPU/GPU taxonomy
  - Multi-layer memory representation
  - Touchscreen & IPS panel indicators
- **Models Implemented**:
  - Ensemble regressors
  - Gradient-boosted regressors
  - Logarithmic price prediction for improved accuracy
- **ML Pipeline**:
  - End-to-end production-ready pipeline
  - Real-time predictions
  - Reproducible inference workflow

---

## 📊 Tech Stack

- **Python** (Data processing, feature engineering, ML pipeline)
- **Streamlit** (Web-based interactive UI)
- **Scikit-learn / XGBoost / Ensemble Models** (Modeling & predictions)
- **Pandas, NumPy** (Data handling)
- **Matplotlib / Seaborn** (Exploratory analysis & visualization)
